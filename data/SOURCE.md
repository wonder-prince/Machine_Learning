# Data source

`bank-additional-full.csv` is from the UCI Machine Learning Repository's [Bank Marketing dataset](https://archive.ics.uci.edu/dataset/222/bank+marketing), specifically its `bank-additional.zip` archive. It contains 41,188 records and 20 input fields plus the target `y`.

Moro, S., Rita, P., & Cortez, P. (2014). *Bank Marketing* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306
